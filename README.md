This is a simple game i made on godot, this isnt anything good, just a simple platformer about collecting stars.

Move Left: A/Left Arrow

Move Right: D/Right Arrow

Jump: W/Space/Up Arrow


Only condition with using the files is credit me and dont use it for any malicious or inappropriate purposes!


I mainly mixed codes from multiple tutorials and guides to make this. All visual assets are by me except the font (Pixelated Elegance), which is made by GGBotNet on FontSpace and was released under public domain.
